# ADR-000: 仓库作为可持续接手的项目记忆

Status: accepted
Recorded: 2026-09-09
Sources: SRC-001, SRC-002, SRC-003
Decision authority: SRC-001 用户确认的方向；不含实现批准
Supersedes: none

## 背景

用户需要任何 AI 或新对话从零衔接，保存决定、讨论、未完成事项和规划。基线已确立仓库记忆方向，但缺少大部分承载文件。

## 选项

仅依赖聊天；只上传代码/结论；保存入口、来源、讨论、决定、状态、问题、任务与交接的关联资料。

这些选项是依据可见材料整理的设计比较；未经完整原对话验证的部分不声称是历史原话。

## 决定或提案

采用仓库外部项目记忆；重大进展必须沉淀并可从入口定位。当前维护流程见协作协议。具体运行时记忆模型不由此 ADR 决定。

## 理由

只保存最终结论不能解释设计原因，也不能恢复工作停点。单靠聊天不能确保新协作者拿到资料。

## 后果与未采用项

增加持续维护成本，需要结构检查和内容验收。来源不完整时必须保留缺口，不能声称已恢复全部历史。

## 未决事项与重审条件

Q001 历史补录、Q010 独立接手测试。当前工作方法可改进但不取消可接手目标。

有新证据或作者改变目标时可重审，不能静默改写旧决定。
