## 新记录格式

每条包含日期、来源及覆盖限制、问题、背景、已有证据、候选与替代项、当前结论及状态、理由、影响、未决项、对应 ADR/任务。未确认的替代项写成“本轮分析”，不要声称此前已经讨论或否决。

新增记录后更新本索引和 Manifest，并将实质决定/待办同步到相应主记录。对话没有产生新决定时不必制造 ADR。
