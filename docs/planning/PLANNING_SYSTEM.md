# Planning System 草案

Status: proposed
Sources: SRC-002, SRC-003, SRC-004

历史中确定需要故事规划能力；没有取得其完整设计。以下层级和操作是待评审提案。

## 规划层级与产物

可从作品意图、阶段/卷目标、情节线、章节、场景到候选事件逐步展开。层级允许按作者习惯调整，不能把某个平台的章节长度规则固化进 Kernel。

一个计划节点可包含目的、前置条件、人物目标、冲突、所需知识、预期变化、来源和未解决问题。记录“预期某事发生”不等于 Event 已发生，更不等于 Canon 已确认。

## 变更流程

作者或 AI 提出计划，Context Engine 提供相关范围的事实，Capability 检查规则和人物/关系等约束。若计划与 Canon 冲突，应展示冲突并提出调整计划或独立的 Canon 变更提案，不能自动改事实配合计划。

写出的场景仍是草稿。作者采纳正文与确认由正文提取的正式事实是否合并为一次操作，需要 Q009 决定；界面不得让一次含糊点击暗中确认不展示的事实变更。

## 可验证用例

计划让角色使用尚未获知的秘密时，标记缺失的获知事件或修改行动动机，不直接向角色知识补秘密。计划改写前文角色受伤情况时，要求展示对后续场景的影响。

未决：Q009 工作流，Q004 版本影响，Q005 知识视角。输入/输出字段尚未冻结，见 [当前任务](../../planning/CURRENT_TASK.md)。
